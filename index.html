How to play

Pop the balloons before they fly away. Each popped balloon gives you one point - try to beat your high score!

Balloon - Pause / continue, back to menu
Double arrow - Wave mode. Opens a speed selector (1x - 5x).

What's new

  • Wave speed - Pick any speed from 1x to 5x using the slider when you enable wave mode.
  • Game scale - Scale the entire game UI in the Game menu.
  • Field scale - Resize the play field in the Game menu.
  • Leaderboard - Top 10 players in Top pad.
  • Best score is now saved on your device.
  • Save game - Save score and mode in pause menu.
  • Secret - There is a hidden secret in the game. Find it.
